# P-H3-Image Workflows

[English](README.md) | **日本語**

[P-H3-Image](https://huggingface.co/PrunaAI/P-H3-Image)を使い、**キャラクターLoRAを学習せずに参照画像からキャラクターの一貫性を維持する**方法を検証する、非公式のプロンプト集・ComfyUIワークフロー公開用リポジトリです。

最初の検証では、正面・側面・背面の**三面図1枚**を `Picture 1` に入力し、キャラクターの顔・髪型・画風を参照しながら、異なる服装・構図・ポーズ・背景の画像を生成しています。

> **公開状況：** 現時点ではプロンプト集のみ公開しています。ComfyUIワークフローは今後追加予定です。PrunaAI公式のリポジトリではありません。

### プロンプトの種類

1. **制服学校：** 教室の机でノートに書き込む、斜め横からの構図。手描きの2Dテレビアニメ風を指定。
2. **セーター振り返り：** ニットセーターを着て後ろ向きから振り返る、カウボーイショット。衣服の編み目や繊細なアニメイラスト調を重視。
3. **ビキニ砂浜：** 砂浜に座って見上げる全身構図。**最終改訂プロンプトの生成結果はまだ未検証**です。

全文は[プロンプト集](prompts/three-view-character-prompts.md)からコピーできます。

## 使い方

1. キャラクターの三面図を用意します。今回の作例では、同じ画像内に正面・側面・背面の**頭部**が並んだものを使用しました。
2. 画像参照に対応するP-H3-Imageの生成・編集ワークフローを開きます。
3. 三面図を **`Picture 1`** として入力します。
4. [プロンプト集](prompts/three-view-character-prompts.md)から英文をコピーし、必要なら衣装や場面を変更して生成します。
5. キャラの同一性・ポーズ・構図・画風を別々に評価します。一貫性の検証ではシードを変えた結果も比較してください。

**ポイント：** プロンプトでは、`Picture 1` の三面図レイアウトを維持するのではなく、**キャラクターデザインと画風の参照資料として使う**よう指定しています。結果はモデル・入力画像・シード・生成設定に依存し、学習済みLoRAと同じ安定性を保証するものではありません。

## 現時点の知見

- 三面図を単に補完するだけでなく、**1人のキャラによる新しい構図**を生成できた例があります。
- 教室・セーターの試行では、衣装や背景を変えても顔や髪型の特徴をある程度維持できました。
- 一方、**画風は参照画像だけでは固定されません。** 教室の背景は、2Dアニメ調を指定しても写実的な光や材質になりがちでした。
- 背景の単純化を強く指示すると、背景だけでなくキャラの顔・衣服まで簡素化される例がありました。
- セーターでは、繊細な線画・多層の陰影・編み目・柔らかいハイライトを記述することで、観察した生成結果の衣服表現が改善しました。

これらは少数の手動検証に基づく**定性的な観察**であり、厳密な比較実験や性能保証ではありません。ビキニ砂浜の改訂版は生成結果をまだ確認していません。
